# PWA Icons

## Overview

This document describes the PWA icon setup for the Financas app.

## Current Approach: Placeholder Icons

The PWA icons are currently **placeholder PNG files** generated by a Node.js script (`scripts/generate-pwa-icons.js`). These placeholder icons satisfy the PWA manifest requirements for **development and testing purposes**.

### Generated Icons

Three icon files are generated in the `public/` directory:

1. **pwa-192x192.png** (192x192 pixels)
   - Used by the PWA manifest as a medium-sized icon
   - Displayed on app install prompts and home screens

2. **pwa-512x512.png** (512x512 pixels)
   - Used by the PWA manifest as a large-sized icon
   - Displayed on app install prompts and home screens

3. **maskable-icon.png** (192x192 pixels)
   - A masked icon variant per the PWA Manifest spec
   - Enables rounded/adaptive icon display on Android

## Generating Icons

To regenerate icons after changes, run:

```bash
npm run icons
```

This script uses a simple PNG generation approach to create valid placeholder files.

## PWA Manifest

The PWA manifest is configured in `vite.config.ts` under the `VitePWA` plugin. It includes:

- App name, description, and branding colors
- Icons with proper sizes and purposes
- Standalone display mode for app-like experience
- Supabase API caching strategy (NetworkFirst with 5-minute expiration)

The manifest is automatically generated at build time as `dist/manifest.webmanifest`.

## Service Worker

The service worker (`dist/sw.js`) is automatically generated by vite-plugin-pwa using Workbox. It:

- Precaches the app shell (HTML, CSS, JS) for offline functionality
- Caches Supabase API responses with a 5-minute TTL
- Cleans up outdated caches
- Enables app navigation routing

## Testing PWA Features

To test PWA installation and offline functionality:

1. **Build and preview**:
   ```bash
   npm run build
   npm run preview
   ```

2. **In Chrome DevTools**:
   - **Application tab** → **Manifest** section: verify manifest loads without errors
   - **Application tab** → **Service Workers** section: verify SW is registered and active
   - **Network tab** → Check "Offline" box → reload → verify app shell loads

3. **Lighthouse audit**:
   - Open DevTools → Lighthouse → PWA category
   - Target: PWA score of 80+ (no critical failures)
